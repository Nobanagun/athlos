# Frontend

## mobile/ (aplicacion principal)

React Native + Expo + TypeScript, con Expo Router para la navegacion.
Es el cliente principal de Athlos para iOS y Android, disenado
offline-first: debe funcionar sin conexion y sincronizar con el backend
(y entre dispositivos) cuando haya red disponible.

## web/ (planificado, no implementado)

Next.js + TypeScript, pensado para un dashboard de administracion y
visualizacion avanzada. Solo existe como carpeta reservada en esta fase;
no se implementara hasta una fase posterior.
